# ВУЗ БЕЗ ПАНИКИ

Неофициальный образовательный проект о поступлении и студенческой жизни в Санкт-Петербурге.

## Новая версия
Статические страницы находятся в `docs/` и работают на GitHub Pages без сборки.

- `index.html`: главная, актуальные мемные форматы в авторской адаптации.
- `bez-filtrov.html`: 72 редакционных ответа с поиском и фильтрами.
- `postuplenie.html`: личный чек-лист с сохранением отметок в браузере.
- `dengi.html`: калькулятор бюджета и вопросы по договору.
- `vuzy.html`: каталог 62 организаций из мониторинга с поиском и фильтрами.
- `perviy-kurs.html`: пять интерактивных ситуаций.
- `rentgen.html`: интерактивный конструктор 48 вопросов к настоящим студентам; сохраняет выбор на устройстве.
- `sprosi.html`: форма подготовки письма команде, без скрытого сбора данных.

Единый дизайн — `style.css`, интерактивы — `app.js`.

## Редакционная политика
Мы не придумываем интервью, не выдаём одиночный опыт за общую оценку университета и всегда отличаем редакционные разборы от историй настоящих студентов. Условия приёма и оплаты следует проверять в официальных источниках.

## Технические особенности
Сайт не имеет собственной базы данных, не собирает ответы на сервере и не обещает, что письмо отправлено, пока пользователь не отправил его в почтовом приложении. Прогресс чек-листа сохраняется только на устройстве.
